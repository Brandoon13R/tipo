# Carpeta de Audio del Lobby (Brilliant)

- **`lobby_chill.wav`**: Pista musical estilo *Chill Puzzle Game / Elevator Bossa Lounge* generada por código en bucle.
- **Para usar tu propia canción `.mp3`**: Coloca tu archivo en esta carpeta con el nombre **`lobby.mp3`** (o **`lobby.wav`**) y el juego la reproducirá automáticamente en el Menú Principal, el Lobby y la Sala de Espera.
